## 🚀 Featured projects

### [FinViet](https://github.com/FinViet-Capstone/finviet-mobile) - AI-powered personal finance app

Capstone project, 4-person team, May 2026 to now.
A personal finance app for Vietnamese Gen Z: an Expo mobile app, a .NET 8 API on PostgreSQL, a Next.js admin dashboard, and Gemini-powered AI.

- Transaction import from bank statements, SMS and receipt photos, auto-categorized with each user's own rules and Gemini.
- Fixed a production import timeout by moving one-AI-call-per-row into parallel batches with their own rate limit: bulk-import capacity went from 6 to 100 requests/min.
- payOS QR payments with a signed webhook and a reconciliation fallback, plus idempotency keys and row locks on all 7 money-moving endpoints.

Repos: [mobile](https://github.com/FinViet-Capstone/finviet-mobile) | [backend](https://github.com/FinViet-Capstone/finviet-be) | [admin web](https://github.com/FinViet-Capstone/finviet-web)

### [DevPrep](https://github.com/dekukoi/devprep) - tailored CV builder

Personal project, July to September 2026, a working prototype.
Built to automate my own resume writing: it stores a developer's skills and experience as structured data and turns them into a CV tailored to a job post.
Next.js, React, TypeScript, PostgreSQL and Prisma; screens designed in Pencil before any code.

## 🤖 How I work with AI

- Every change goes through spec, branch, test and review, with Claude Code doing the typing and me doing the thinking.
- Each project keeps context docs (spec, coding standards, a per-feature log) so the agent stays consistent across sessions.
- Nothing gets merged that I can't explain in my own words.
